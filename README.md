# CSS844Module2VCFCharacterization

Python code made for module 2 of CSS 844 at Michigan State University in spring 2025.

This code reads in three VCF files, made by aligning genomic data to three different reference genomes, then converts them to pandas dataframes to compare them.
Then, graphs made to compare quality the control metrics of different reads.
Necessary VCF files, quality metric csv, and .txt files not in repo.
